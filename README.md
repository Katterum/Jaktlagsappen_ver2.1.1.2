# Katterums jaktlag v2.1.1.1

Bygger additivt på låst v2.0.2.

Nytt:
- Inloggning med användarnamn och lösenord via Supabase Edge Function `username-login`.
- Roller: Administratör, Jaktledare, Medlem.
- Inloggad medlem förväljs i relevanta personfält.
- Förberett för skapad/ändrad av.

Före GitHub-uppladdning: ersätt `PASTE_YOUR_PUBLISHABLE_KEY_HERE` i `supabase-config.js`.
